
## Project Overview
A user management application developed using React and Vite.

## Technologies Used
- React.js
- JavaScript
- Vite
- CSS
- JSONPlaceholder API

## Features
- Fetch and display users from an API
- Add users using a form
- Edit user details
- Delete users
- Form validation
- Loading message while fetching users

## React Concepts Practiced
- Functional components
- Props and component communication
- useState
- useEffect
- Event handling
- Form handling and validation
- Conditional rendering
- map() method
- API integration

## API
https://jsonplaceholder.typicode.com/users

## How to Run
1. Clone this repository.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL displayed in the terminal.
